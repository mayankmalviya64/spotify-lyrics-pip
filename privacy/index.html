Privacy Policy for Spotify Lyrics Pop-Out

Last updated: August 9, 2026

Spotify Lyrics Pop-Out is a Chrome extension that displays synchronized lyrics for the track playing in Spotify Web.

Data used

The extension reads the current track title, artist, album artwork, playback position, and playback state from open.spotify.com. It sends the track title, artist, and duration to LRCLIB (lrclib.net) solely to find matching synchronized lyrics.

Data storage and sharing

Spotify Lyrics Pop-Out does not operate its own server, create user profiles, sell personal data, or use data for advertising, credit decisions, or purposes unrelated to displaying synchronized lyrics. Track metadata is shared only with LRCLIB as required to retrieve lyrics and is subject to LRCLIB's service practices.

The extension does not collect passwords, payment information, private messages, health information, or precise location data.

Permissions

The extension uses Chrome's tabs permission to locate an open Spotify Web tab and communicate with it. Host access is limited to open.spotify.com for playback information, api.spotify.com for Spotify Web session actions such as playlist, queue, and library controls, and lrclib.net for lyric lookup.

Changes

This policy may be updated when the extension's functionality or data practices change. The canonical privacy policy is available at mayankmalviya64.github.io/spotify-lyrics-pop-out/privacy/ .
